# Sprint v0.3: Relógio da Investigação, Mesa Diegética Noir e Teia Social de Personagens

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform Detetive IA into a high-tension, tactile 1940s detective experience by adding an action-economy Night Clock (21:00 to 04:00) with warrant limits to stop brute-force guessing, a layered 3-tier secret system with interconnected suspect drama, a diegetic 1940s desk interface, and harmonious Film Noir visual assets generated via Higgsfield AI.

**Architecture:** Monolithic Go backend with pure SQLite (`modernc.org/sqlite`) running under a 30MB RAM operational envelope. The database schema is extended to track `time_remaining_minutes`, `warrants_remaining`, and suspect secret tiers. Frontend is rendered via embedded templates and vanilla CSS/JS simulating a wooden detective desk with Manila dossiers, typewriter text, and Polaroid photos.

**Tech Stack:** Go 1.24+, SQLite in WAL mode, CSS3 / Modern Vanilla JS, Higgsfield GPT Image 2 / Nano Banana, Maestri CLI & canvas portals.

**Spec:** [`docs/RESEARCH_FEEDBACK_REPORT.md`](file:///C:/Users/limae/Documents/Projects/Detiv/docs/RESEARCH_FEEDBACK_REPORT.md)

## Global Constraints
- Maximum RAM consumption: <30MB at runtime (strict ceiling: 60MB).
- Monolithic single-binary with embedded assets (`embed.FS`) and zero CGO dependencies.
- Pure Go SQLite without external C library (`modernc.org/sqlite`).
- Every new feature must be backed by automated tests (TDD) before implementation.
- All tasks must be recorded on the Maestri Canvas Note `Projeto` in descending order.

## Review Focus
1. Negative or zero time manipulation: Client attempting to send actions when clock has reached 04:00 (time_remaining <= 0) must be rejected with HTTP 400 and Game Over payload.
2. Accusation without corroborating clues: Player attempting to accuse without exactly 2 attached clue IDs must receive HTTP 400 Bad Request ("anexe duas pistas para fundamentar o mandado").
3. Strike exhaustion: A second incorrect accusation must mark the investigation as `FAILED` (badge revoked) and prevent further actions.
4. Stress tier boundary conditions: Interrogating suspects with stress crossing 30% and 70% must reliably transition responses between Tier 1 (Alibi), Tier 2 (Petty Crime), and Tier 3 (Breakdown/Truth).
5. Room mode and Solo mode parity: Time tracking and warrants must operate seamlessly in both single-player investigations and multiplayer procedural rooms.
