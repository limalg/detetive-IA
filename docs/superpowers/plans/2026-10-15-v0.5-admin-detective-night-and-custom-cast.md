# Plano de Implementação: Detetive IA v0.5 - Painel Admin, Telemetria OpenTelemetry, Detective Night e Personagens Personalizados

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans / maestri team orchestration to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar painel de administração (`/admin`) protegido com configuração dinâmica do modelo de IA e visualizador de logs/telemetria OpenTelemetry; pré-configurar as credenciais da nota `credencias` (`https://router.ofertasshow.shop/v1`, modelo `ondegastei`); converter a base de mistérios para o formato Detective Night (envelopes 1, 2 e 3) e permitir criação de salas com personagens reais/fictícios organizados pela IA.

**Architecture:** 
- Backend Go monolítico ultraleve (<40MB RAM).
- Suporte a cliente IA Universal com endpoint OpenAI-compatible (`/chat/completions`) com fallback resiliente.
- Sistema de telemetria e logger estruturado em buffer circular (traces, spans, status codes, latência, contadores).
- Banco SQLite com tabela `system_settings` e `cases` expandidos para os casos Detective Night.
- Interface Web Noir com rota `/admin` e criação de salas com seleção de caso e upload de personagens.

---

### Task 1 (Perito): Configuração Dinâmica de IA, Credenciais Padrão e Telemetria OpenTelemetry
- **Arquivos:**
  - `internal/db/schema.go`: Tabela `system_settings` (`key`, `value`, `updated_at`) e migrações.
  - `internal/telemetry/telemetry.go`: Logger estruturado em buffer circular com traces OpenTelemetry (`trace_id`, `span_name`, `duration_ms`, `status`, `message`, `timestamp`).
  - `internal/game/ai_interrogator.go`: Cliente Universal OpenAI-compatible com Bearer Auth + fallback, carregando da tabela de configurações.
  - `internal/server/handlers.go` & `internal/server/server.go`: Endpoints `/api/admin/settings`, `/api/admin/telemetry`, `/api/admin/logs`, `/api/admin/test-ai` e proteção de acesso à rota `/admin`.
- **Testes:** `internal/server/admin_test.go`, `internal/telemetry/telemetry_test.go`.

### Task 2 (Perito): Motor Detective Night e Organizador de Personagens com IA
- **Arquivos:**
  - `internal/game/detective_night.go`: Catálogo dos casos Detective Night (*Fazenda Coração da Serra*, *A Morte de Sherlock Holmes*, *O Roubo da Carga 479*, *Estrela Fria*) estruturados nos 3 Envelopes (O Caso, Vozes Suspeitas, Evidências Forenses).
  - `internal/game/weaver.go`: Integração com IA para receber personagens customizados (fictícios ou reais) e distribuir os papéis e álibis dinamicamente.
  - `internal/room/room.go`: Criação de sala automática vinculada ao caso escolhido e aos personagens atribuídos.
- **Testes:** `internal/game/detective_night_test.go`.

### Task 3 (Lince): Interface Web do Painel Admin (/admin)
- **Arquivos:**
  - `web/templates/admin.html` (ou seção dedicada no index.html com modal/view): Dashboard de controle administrativo.
  - `web/static/js/admin.js`: Lógica de salvamento das configurações de IA, teste de conexão da IA e stream de logs/telemetria OpenTelemetry em tempo real.
  - `web/static/css/style.css`: Estilização Noir do painel administrativo.
- **Testes:** `web/web_test.go`.

### Task 4 (Lince): Interface Web Detective Night (3 Envelopes e Personagens Personalizados)
- **Arquivos:**
  - `web/templates/index.html`: Seletor de casos Detective Night com visual dos 3 Envelopes (Envelope 1: O Caso, Envelope 2: Vozes Suspeitas, Envelope 3: Evidências).
  - Formulário para adicionar personagens (nome, foto/avatar, notas) reais ou fictícios antes de iniciar a sala.
  - `web/static/js/app.js`: Integração com os novos endpoints de sala e caso Detective Night.
- **Testes:** `web/web_test.go`.
